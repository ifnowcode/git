Network Router Security Quick Check

  1. Check that the administrator password is changed from the default
  2. Verify the firmware is up-to-date
  3. Disable remote management if not needed
  4. Review wireless encryption settings for WPA2 or WPA3
  5. Ensure a secure guest network is setup if needed
  6. Check no unauthorized devices are connected to the network
  7. Disable Wi‑Fi Protected Setup (WPS) unless needed

Remember default router passwords are printed on the box so be aware of who has access to it if you use the defaults. Put in a safe or locked place if possible.

Note: The Device Access Code (password) gives full control over the router.

Network Router Security Hardening Audit

  • Change default admin username and password: Default credentials are widely known and easily exploited.
  • Update router firmware: Install the latest firmware to patch vulnerabilities and improve stability.
  • Disable remote administration: Turn off remote access unless absolutely required.
  • Use WPA3 (or WPA2) Wi‑Fi security: Avoid outdated protocols like WEP or WPA.
  • Set a strong Wi‑Fi password: Use a long, unique passphrase for all wireless networks.
  • Disable WPS (Wi‑Fi Protected Setup): WPS is vulnerable to brute‑force attacks.
  • Enable a guest network: Keep visitors off your main LAN to protect internal devices.
  • Disable UPnP: Prevent devices from automatically opening ports without your knowledge.
  • Review open ports and services: Close anything not explicitly needed.
  • Check connected devices: Remove or block unknown or suspicious devices.
  • Enable router firewall: Ensure the built‑in firewall is active and logging traffic.
  • Disable unused features: Turn off VPN passthrough, DMZ, or IPv6 if not in use.
  • Use DNS filtering or secure DNS: Switch to a trusted DNS provider with security features.
  • Limit admin access to LAN only: Ensure the admin panel is only reachable from inside the network.
  • Set up network segmentation: Separate IoT devices from computers and phones.
  • Enable logging and alerts: Turn on security logs and email alerts for suspicious activity.
  • Backup router configuration: Save a secure copy of your known‑good configuration.
  • Factory reset if compromised: If you suspect tampering, reset and reconfigure from scratch.

Implement what you can but never use WPA1.
